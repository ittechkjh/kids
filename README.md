# 👶 아이키움 맵 (KidsInfra)

> **분산된 공공데이터(보육·교육·의료·주거·도서관)를 결합하여, 미취학 및 초등 자녀를 둔 가정이 거주지 선택과 일상 육아에서 겪는 정보 탐색 비용을 최소화하는 지도 기반 올인원 인프라 플랫폼**

---

## 🌟 주요 구현 기능

### 1. 🏫 주거 & 안심 통학 지도 (초품아 & 보육 인프라)
- **초품아 안심 통학 분석**: 아파트 단지 선택 시 배정 초등학교(학교알리미 학구도) 자동 매칭, 도보 통학 거리·시간 및 차도 횡단보도 횟수 표시
- **스쿨존 & 보행 안전 오버레이**: 통학로 폴리라인 애니메이션, 어린이보호구역(반경 300m) 범위, 방범/과속 CCTV 설치 대수 및 보행자 사고 다발 주의 지점 지도 시각화
- **단지 인근 보육 시설 비교**: 반경 1km 내 국공립·민간 어린이집 및 유치원의 인가정원, 현원, 입소 대기 인원, 교사 1인당 아동 수, 야간연장 보육 여부 일괄 비교

### 2. 🏥 긴급 의료 & 안심 케어 파인더 (실시간 소아 의료)
- **실시간 달빛어린이병원 & 소아응급실 & 심야약국 필터**: 현재 시각(또는 평일 야간 22:30 / 일요일 16:00 / 심야 00:30 시뮬레이션 모드) 기준 영업 중인 기관만 즉시 필터링
- **원터치 전화 & 내비게이션 딥링크**: 야간 응급 시 바로 전화 걸기(`tel:`) 및 카카오맵 / 네이버지도 길안내 원터치 연결
- **[추가 기능] 아이 체중별 해열제 1회 정량 & 교차복용 계산기**: 아이 체중(kg)과 현재 체온(℃) 입력 시 아세트아미노펜 계열 및 이부프로펜/덱시부프로펜 계열의 1회 권장 복용량(mL)과 교차복용 가이드 즉시 계산
- **[추가 기능] 증상별 소아응급실 vs 달빛병원 판단 가이드**: 생후 100일 미만 발열, 열성 경련, 크루프(급성 후두염), 야간 고열 등 증상별 대처 수칙 및 출발 전 체크리스트 제공

### 3. 📚 주말 나들이 & 문화·독서 큐레이션
- **공공도서관 연령별 인기도서 & 실시간 재고 조회**: 영유아(0~6세), 초등 저학년(7~9세), 초등 고학년(10~12세) 대출 베스트 도서 목록 및 내 주변 거점 공공도서관의 실시간 대출 가능 권수·서가 위치 표시
- **지자체 어린이 무료/저렴 주말 체험 캘린더**: 유아숲체험원, 환경생태학습원, 책박물관, 어린이 천문과학관, 육아종합지원센터 주말 프로그램 일정 및 예약 안내

### 4. 📊 아파트 단지별 "아이키움 인덱스" & 바이럴 카드뉴스
- **4대 영역 종합 평가 리포트**: 통학 안전성, 야간 소아의료 편의성, 보육/사교육 접근성, 독서/생태 문화 환경을 종합 점수화(S / A+ 등급) 및 SVG 레이더 차트 시각화
- **맘카페·입주민 단톡방 공유용 고해상도 카드뉴스(PNG) 다운로드**: HTML5 Canvas 기반으로 1080×720 카드뉴스 이미지를 즉시 생성·다운로드
- **단지별 고유 공유 링크 (Deep Link)**: `?apt=PG-101` 형태의 고유 URL을 생성하여 원하는 단지 리포트로 바로 유입 가능
- **실거주 학부모 익명 한 줄 통학·보육 후기**: 단지별 실제 통학 및 어린이집·소아과 이용 후기 작성 및 평점 공유

### 5. ⚡ 추가 확장 기능
- **단지 대 단지 1:1 비교 배틀**: 고민 중인 두 아파트 단지를 선택해 아이키움 점수, 배정초 거리, 횡단보도 수, 늘봄학교 수용률, 학원가 규모, 강남/판교 출퇴근 시간, 국토부 전용 84㎡ 실거래가까지 8개 핵심 지표 승패 비교
- **맞벌이 육아 타임라인 시뮬레이터**: 부부 출근(집 출발) 및 귀가(단지 도착) 시각과 자녀 연령을 입력하면 07:30~22:00 타임라인과 돌봄 공백 시간을 자동 계산하고, 단지 내 야간연장 어린이집·늘봄학교 솔루션을 매칭
- **우리 아이 연령 맞춤 필터 & 관심단지 알림장**: 상단 바에서 자녀 연령대 선택 시 전 메뉴 맞춤 필터링 및 관심단지 로컬 북마크 지원

## 🚀 실행 및 배포 방법

### 1) GitHub Pages 배포
1. 본 저장소(`https://github.com/ittechkjh/kids`)의 **Settings → Pages** 메뉴로 이동합니다.
2. **Build and deployment**의 Source를 `Deploy from a branch`, Branch를 `main` / `/(root)`로 지정하고 저장합니다.
3. 배포 완료 후 `https://ittechkjh.github.io/kids/` 주소에서 즉시 서비스가 동작합니다.

### 2) Cloudflare Workers API 게이트웨이 배포 (선택)
실시간 공공데이터포털 API(심평원, 보건복지부, 국토교통부, 도서관 정보나루)를 연동하려면 `cloudflare-worker/` 디렉터리에서 아래 명령을 실행하세요:
```bash
cd cloudflare-worker
npx wrangler kv:namespace create KIDS_INFRA_KV
npx wrangler secret put DATA_GO_KR_API_KEY
npx wrangler secret put DATA4LIBRARY_API_KEY
npx wrangler deploy
```
배포된 Worker URL을 웹앱 우측 상단 **[API 하이브리드]** 설정 모달에 입력하면 실시간 API 응답이 연동됩니다.
